# 설계 결정

## 2026-09-14 · v2
사용자가 요구한 브라우저 단독 HTML/CSS/JS 3파일 구조를 유지했다. 원기획의 Streamlit/학습 모델은 프론트엔드 시연 범위 밖이다. 교체 없이 화면 작업과 백엔드 연결을 분리한다.

사용자 최신 요청에 따라 총점·자동 방문 인원·방사형/막대·사진 포함 프로필·관리자 평을 추가했다. 과거 기획의 임의 위험점수 확정 금지 취지를 지키기 위해 계산식과 임계값은 공개된 시연 가정으로 표시한다. 실제 사고 확률로 해석하지 않는다. 실데이터 검증 전 운영 사용은 범위 밖이다.

UI 지침 v2.5의 정보 위계, 역할별 토큰, 폼 저장/취소/실패, 44px 주요 조작, 화면 폭별 재배치, 그래프 숫자 대안을 채택했다. 테마·반투명·고급 모션은 미채택. 모바일은 같은 기능의 하단 탐색이며 네이티브 설치 앱이 아니다. 원본 PDF와 과거 대화 없이 본 문서와 구현으로 이어간다.

## GitHub 초기 이관
공통 작업·인계 지침 r2를 통째로 복사하지 않고 AGENTS 및 역할별 문서로 정착한다. 기존 원격은 빈 저장소로 확인했다. 제품 소스는 사용자에게 전달된 v2 세 파일과 동일하게 이관한다. 테스트만 개인 PC 경로/외부 예시 파일 의존성을 제거하고 고정 개발 의존성과 잠금 파일을 추가한다.

되돌릴 때는 공유 이력을 지우지 않고 git revert를 사용한다. localStorage 데이터 형식 변경이 필요하면 마이그레이션과 복구 정책을 먼저 정한다.
