# 구조와 계산식

## 파일과 데이터
index.html: 공통 헤더/탐색/방문 현황/메인/미저장 확인 dialog.
style.css: 역할별 토큰과 PC·중간·모바일 레이아웃.
script.js: 더미 데이터, 검증, localStorage, 점수/분류, 렌더링, 이벤트, URL 이력.

저장 키 ondol-prototype-v1 유지. 6명 가상 데이터로 시작하고 기존 10개 변수 데이터에 신상정보 기본값을 보완한다. 사진은 JPG/PNG/WebP 최대 2MB, 긴 변 360px JPEG로 변환하여 저장한다. 사진 없으면 실루엣. 관리자 편집은 프론트엔드 시연일 뿐 실제 권한 경계가 아니다.

## 원래 핵심 변수
독거 0/1, 질환 수 0/1/2/3(3개 이상), 이동 0/1/2, 건강 악화 0/1, 가족 연락 0/1/2, 사회 교류 0/1/2, 정서 0/1/2, 주거 0/1/2, 방문 경과일 0~3650, 미응답 0/1/2(2회 이상). 가족·사회 값은 클수록 연결이 많다. 신상정보는 모델 변수가 아니다.

## 시연 점수
생활=독거×10. 건강=질환/3×10+이동/2×10+건강악화×10. 관계=(2-가족)×5+(2-사회)×5. 정서=정서×5. 주거=주거×5. 공백=min(경과일,30)/3+미응답×5. 합계를 반올림해 0~100점.

방사형은 각 영역의 만점 대비 비율, 막대는 실제 배점. 자동 평은 비율이 높은 두 영역을 설명한다. 관리자 평은 별도 comment이며 자동 계산을 덮어쓰지 않는다.

오늘 방문 제안=(60점 이상 OR 미응답 2회 이상 OR 경과일 14일 이상) AND 오늘 완료 아님. 중복은 한 명. 완료 표식 visited는 로컬 날짜이며 입력 경과일을 자동으로 바꾸지 않는다.

유형은 건강·관계·정서·주거의 단순 조건 조합. 서로 다른 2개 영역 이상이면 복합, 단일 건강/관계면 해당 유형. 정서 또는 주거만 해당하면 유형 확인 필요. 실제 K-means/XGBoost 없음.

## 복구와 제한
저장 실패는 폼을 유지하고 재시도를 안내한다. 저장 전 화면 이동은 취소 확인. 새로고침 시 미저장 초안은 복원되지 않는다. URL hash는 화면/대상/목록 조건을 보관한다. 파일 URL·브라우저 정책에 따라 저장 위치가 달라질 수 있다.
